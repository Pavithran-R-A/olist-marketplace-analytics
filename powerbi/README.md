# Power BI source package

This folder contains a typed TMDL semantic-model source specification, DAX measures,
and a minimal PBIP manifest. It is intentionally labelled unvalidated: Power BI Desktop
was not installed on the build machine, so the manifest has not been opened or rendered.
Microsoft's official [TMDL overview](https://learn.microsoft.com/en-us/analysis-services/tmdl/tmdl-overview)
defines the object syntax and typed column properties used here.
